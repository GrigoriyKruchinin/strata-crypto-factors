# Гайд пользователя: Strata как инструмент исследования

Strata проверяет на истории и на живых данных, приносят ли «факторные» стратегии на криптофьючерсах доход после всех издержек. Реальных сделок нет: работают только бэктест (проверка на прошлых данных) и виртуальный счёт (paper-trading, сделки «на бумаге»).

---

## 1. Что нужно

- [ ] Python 3.12 и `uv` (менеджер пакетов). Проверка: `uv --version`. Если нет: `curl -LsSf https://astral.sh/uv/install.sh | sh`, затем перезапусти терминал.
- [ ] Около **10 ГБ** свободного места (история цен по ~700 монетам).
- Ключи биржи **не нужны**: используются только публичные данные Binance.

**Что НЕ делать:**
- ❌ Не создавай API-ключи биржи: проект их не использует.
- ❌ Не присылай токены и пароли в чат и не коммить файл `.env`.

## 2. Установка

```bash
cd strata-crypto-factors
cp .env.example .env     # файл с настройками, хранится только у тебя
uv sync                  # установка зависимостей
make check               # проверки кода и тесты: в конце должно быть "passed"
```

## 3. Telegram (по желанию)

Нужен, если хочешь получать отчёты виртуального счёта в Telegram.

1. [ ] В Telegram найди **@BotFather**, отправь `/newbot`, задай имя и username (оканчивается на `bot`). Получишь **токен** вида `1234567890:AAH...`.
2. [ ] Напиши своему боту любое сообщение, затем открой в браузере `https://api.telegram.org/bot<TOKEN>/getUpdates` и найди `"chat":{"id":123456789` — это твой chat id.
3. [ ] Впиши оба значения в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=<токен>
   TELEGRAM_CHAT_ID=<chat id>
   ```

> ⚠️ Токен работает как пароль. Если он утёк, в @BotFather выполни `/revoke` и получи новый.

## 4. Скачивание истории

```bash
make download-history
```
- [ ] В конце строка `symbols=... failed=0`.

Скачиваются дневные свечи и история фандинга (платежей между покупателями и продавцами фьючерсов) по всем фьючерсам Binance с 2020 года, **включая монеты, снятые с торгов**: без них результат был бы приукрашен. Первый раз занимает 1–2 часа; если оборвалось, запусти ещё раз — скачанное берётся из папки `data/`. Отчёт о качестве данных: `data/quality_report.json`.

## 5. Исследование

```bash
make backtest ARGS="--spec funding_carry_14"   # одна стратегия на периоде 2020–2023
make research STEP=train                       # все 18 заранее заданных вариантов
make research STEP=robustness                  # проверки: случайные сигналы, без лучших монет и др. (~30 мин)
make research STEP=charts                      # графики в docs/reports/assets/
```
- Результаты: `docs/research/results/*.json`; журнал всех прогонов: `docs/research/experiment-log.jsonl` (видно, сколько вариантов перепробовано).
- ⚠️ Контрольный период (2024 – октябрь 2026) уже использован в исследовании октября 2026 и заблокирован: шаг `holdout` повторно не запустится. Новую идею нужно заранее описать и проверять на данных, которых ещё никто не видел (например, на более свежих).

## 6. Виртуальный счёт (paper-trading)

Один цикл: обновить данные, провести день виртуального счёта, прислать итог в Telegram.

```bash
make paper
```
Счёт и сделки хранятся в файле `data/strata.db`. Чтобы цикл шёл сам каждый день, добавь его в расписание `cron` (в WSL перед этим включи cron: `sudo service cron start`):
```bash
crontab -e
# строка: каждый день в 00:15 UTC
15 0 * * * cd /путь/к/strata-crypto-factors && /home/<user>/.local/bin/uv run strata paper-cycle >> data/paper.log 2>&1
```
Компьютер должен быть включён в это время; пропущенные дни догонятся при следующем запуске.

## 7. Как читать отчёт

Главный отчёт исследования: `docs/reports/stage-1-go-no-go.md`. Ключевые показатели:

| Показатель | Что значит |
|---|---|
| Плюс к депозиту (% в месяц) | Средний чистый доход в месяц после всех издержек |
| Годовая доходность | Сколько процентов в год после комиссий и фандинга |
| Максимальная просадка | Самое глубокое падение счёта от пика |
| Sharpe | Доход на единицу риска: чем выше, тем стабильнее рост |
| Издержки ×2 | Выдержит ли стратегия вдвое большие комиссии и проскальзывание |
| Случайные сигналы | Лучше ли стратегия, чем тот же портфель на случайном выборе монет |
| Без лучших монет | Не держится ли весь доход на 1–2 удачных монетах |

В конце отчёта есть блок **«Простыми словами»**.

> ⚠️ Все результаты исторические или симуляционные. Это не прогноз и не финансовый совет.
